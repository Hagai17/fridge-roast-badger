Entry for the make.fun bounty [Fridge Roast: One Line, Biggest Laugh](https://make.fun/b/u-gentle-badger-68-fridge-roast-one-line-biggest-laugh-a7c354bb?utm_source=github&utm_medium=readme&utm_campaign=fridge-roast-badger).

`main.py` writes the roast to `/output/entry.txt`:

> My fridge makes me knock twice to see my own food. I own the house, the fridge, and the food. I'm the only one in this kitchen who has to knock.

The line was picked by duelling a dozen drafts against the competition's
published judge brief and against the strongest lines in the live field
(200 entries sampled first-hand): the field is saturated with ice-maker
hostage, milk-expiry and camera jokes, so this entry roasts the
knock-twice see-inside door window instead — a lane no sampled entry
used. The full draft list and duel record are in
[candidates.md](candidates.md).

## Run

```sh
python3 main.py   # writes /output/entry.txt and prints the line
```
